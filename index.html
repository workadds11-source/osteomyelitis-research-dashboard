Research question

What are the clinical patterns and treatment outcomes of osteomyelitis among patients attending CHUK and RMTH between 2023 and 2025?

Specific objectives

4 objectives

01 · Socio-demographic profile

Age, sex and educational level of patients diagnosed with osteomyelitis.

02 · Clinical patterns

Acute vs chronic disease, anatomical site and staging classification.

03 · Treatment approaches

Antibiotics, surgical interventions and combined therapy.

04 · Treatment outcomes

Cure, recurrence, complications and duration of hospital stay.

Important implementation note

GitHub Pages is a static host. A public page cannot securely write a newly uploaded PDF back into your GitHub repository without a server-side service or GitHub App/token. This version therefore processes uploaded PDFs locally and persistently in the browser, updates the dashboard immediately, and keeps the repository itself free of private research files. A secure backend can be added later if you want automatic repository publishing.
