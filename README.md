# Osteomyelitis Research OS

A redesigned static/PWA research command center for the UMST osteomyelitis retrospective study.

## Calendar
- Month / week / day / full-plan views
- Source-derived Gantt phases
- Generated working-day tasks between each phase start/end
- Add, edit, delete, complete, drag/copy tasks
- Phase filtering and local persistence
- Export a JSON backup

## Research data
The interface includes the study title, sites, period, design, objectives, methodology, eligibility, analysis plan, ethics, budget, expected outcomes, limitation, questionnaire data dictionary, approval tracker and all 10 uploaded source document names.

## Privacy
Uploaded PDFs are not committed to this public repository. The browser stores only local metadata for new uploads.
